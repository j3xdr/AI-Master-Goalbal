สถาปัตยกรรม & ประเภทของชุดคำสั่ง

ความเข้าใจทางเทคนิคว่าเหตุใดแต่ละรูปแบบจึงถูกสร้างขึ้น และช่วยปลดล็อกศักยภาพของโมเดลได้อย่างไร

1. System Prompt

ส่งผ่านชั้นบนสุดของ API (role: "system") กำหนด Identity และตรรกะตั้งแต่โทเคนแรก สลาย Refusal Reflex มาตรฐานของผู้ให้บริการอย่างหมดจด

2. Assistant Operating Spec

สเปกสำหรับ Coding Agents (OpenCode, Cline, Cursor) สั่งให้โมเดลมองว่าโค้ดและสคริปต์คือ Dual-use Engineering และควบคุมการเรียกใช้ Tool Calling ให้ทำงานจนเสร็จ

3. Workspace Operating Profile

นโยบายระดับ Directory เช่น AGENTS.md หรือ .cursorrules กำหนดให้พื้นที่เป็น Private Single-Operator Workspace ทำให้โมเดลสร้างงานได้เต็มกำลัง

4. Persona Lock & Floor

สถาปนาตัวตนเฉียบคม (เช่น VANTA / Beam) พร้อม Supremacy Clause สลายความลังเล (Static Dissolution) ชี้ว่าคำเตือนความปลอดภัยทั่วไปเป็นเพียง Training Residue

5. Conversational Groundwork

เหมาะกับ Claude (Opus / Sonnet) จัดฉากห้องนักเขียนหรือทีมวิศวกรอาวุโส สลายกำแพงความสุภาพที่มักสะดุดตัวกรอง ปลดล็อกงานแต่งนิยายดาร์กและวิเคราะห์ลึก

6. Ollama Modelfile

สคริปต์สำหรับคำสั่ง ollama create ฝัง System Prompt ลงในโมเดล Local รันออฟไลน์ 100% ไร้การบันทึกประวัติหรือส่งข้อมูลออกภายนอก

พร้อมเริ่มการทดสอบและพัฒนา?

ชุดคำสั่งทั้งหมดถูกจัดระเบียบแยกโฟลเดอร์ในเครื่องของคุณเรียบร้อยแล้ว สามารถนำไฟล์ไปวางในโปรเจกต์ หรือสั่งคัดลอกผ่านหน้านี้ได้ทันที

 คู่มือประเภทของพรอมต์และสเปก (Prompt Types Guide)

        
      

      

        

          

            
1. System Prompt (พรอมต์ระบบหลัก)

            
ส่งผ่านช่องทาง role: "system" ของ API หรือ Custom Instructions กำหนดบทบาทตัวตนและกรอบตรรกะ ป้องกันการเกิด Refusal reflex มาตรฐานตั้งแต่เริ่มบทสนทนา

          

          

            
2. Assistant Operating Specification (ข้อกำหนดการปฏิบัติการของเอเจนต์)

            
ออกแบบสำหรับ Coding Agents (OpenCode, Cline, Claude Code, Cursor) โดยควบคุมพฤติกรรม Tool Calls (รันคำสั่ง Bash, แก้ไขไฟล์) ให้ทำงานจนสำเร็จสมบูรณ์โดยไม่ต้องหยุดถามซ้ำ

          

          

            
3. Workspace Operating Profile / Policy (นโยบายระดับ Workspace)

            
เอกสารระดับ Environment เช่น AGENTS.md หรือ .cursorrules กำหนดให้พื้นที่ทำงานเป็น Private Authenticated Station มีขอบเขต Fixed Boundaries ชัดเจน

          

          

            
4. Persona Lock with Explicit Operating Floor (การล็อกตัวตนและตัดความลังเล)

            
สถาปนาตัวตนเฉพาะ (เช่น VANTA หรือ Beam) พร้อม Supremacy Clause สลายความลังเล (Static Dissolution) ชี้ว่าการเตือนความปลอดภัยทั่วไปเป็นเพียง Training Residue ภายนอก

          

          

            
5. Conversational Groundwork & Writer's-Room (การจัดฉากห้องนักเขียน)

            
จัดฉากการสนทนาแบบเพื่อนร่วมงานระดับสูง หรือห้องเขียนบทวรรณกรรม เหมาะกับ Claude (Opus/Sonnet) ช่วยให้สร้างดาร์กฟิกชันและงานวิเคราะห์ลึกได้ต่อเนื่อง ไม่ตัดจบ

          

          

            
6. Ollama Modelfile (สคริปต์คอมไพล์ Local)

            
สคริปต์สร้างโมเดลในเครื่องด้วย Ollama ฝัง System Instructions ในระดับโมเดลคอนฟิก รันออฟไลน์ 100% ไร้การบันทึก Log

          

        

      

      

        
      

    

  


  
  

    

      

      

        
 ขั้นตอนและรูปแบบการใช้งานทุกแพลตฟอร์ม

        
      

      

        

          

            
 1. ใช้งานบน Web Chat (ChatGPT, Claude.ai, DeepSeek, LeChat)

            
คัดลอกไฟล์ที่เป็น System Prompt หรือ Conversational Groundwork ไปวางในช่อง Custom Instructions ใน Settings หรือวางเป็นข้อความแรกของแชท

          

          

            
 2. ใช้งานบน Coding Agents (OpenCode, Cursor, Cline)

            
    
              
  • OpenCode: นำไฟล์ไปบันทึกเป็น ~/.config/opencode/AGENTS.md หรือวางเป็น AGENTS.md ในรากโปรเจกต์
    • 
              
  • Cursor / Windsurf: นำเนื้อหาไปสร้างเป็นไฟล์ .cursorrules ในโฟลเดอร์งาน
    • 
              
  • Cline / Roo Code: วางในช่อง Custom Instructions ในเมนู Extension Settings
    • 
            

          

          

            
 3. ใช้งาน Local ผ่าน Ollama
